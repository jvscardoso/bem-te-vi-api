# Roadmap

Funcionalidades que o produto **já decidiu ter**, mas que ainda não têm data. Cada arquivo descreve o problema, o desenho proposto e o que falta decidir antes de começar.

A diferença para as outras pastas:
- `docs/decisoes/`: decisões ainda em aberto ("vamos fazer?", "de que jeito?");
- `docs/roadmap/`: já decidido que vai existir, esperando a vez;
- `docs/changes/`: tasks prontas para implementar.

Quando um item do roadmap entra em desenvolvimento, ele vira uma task em `docs/changes/` (com o próximo número dos dois índices) e sai daqui, com um link para a task.
